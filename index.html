What is it?

A mix of several ideas combined in one, trying to keep the best of each.

Usage rests on 3 key points: semantic HTML, ARIA usage and CSS variables.

Family Hierarchy

An abstract way to think about CSS inheritance, covering relations such as first child and last child.

Add the .parent class to the tag that is really the parent.

Then pass the heritage the children inherit: colors, spacing and font-related values.

To stop a specific tag from inheriting from the parent, give it the .bastard class.
